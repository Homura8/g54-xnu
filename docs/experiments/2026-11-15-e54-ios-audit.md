# E54: iOS 16.7.16 UI & subsystem audit over the USB console

**Result: PASS (read-only audit on E53c / kernel K23, CI run 43615780625).** Used the
macOS USB console (`1209:0003`) to systematically exercise iOS 16.7.16 UI flows,
built-in apps, Settings panes, side keys, and the 8,990-line kernel log ring,
allowing 5–7 s after app/pane transitions for software rendering. Eight new
issues (#15–#22) were logged in [status.md](../status.md).

## Method & USB console note

- **Device & image:** G54 (`cancunf`) running E53c (`boot_a`, K23 = 0200–0210,
  best boot line with `g54usb=1`, no flash performed).
- **macOS open/replay quirk (issue #15):** Opening the CDC-ACM port on macOS
  asserts `DTR=1, RTS=1` (`setup 21 22 0003`) inside `os.open()` before
  `TIOCMBIC` clears RTS (`0001`). Patch `0210` sees `DTR 0->1` with `RTS=1` and
  replays the entire log ring (`port open (replay)`) on every `g54_usb.py` call;
  if an older `G54 USB: ok pong #1` is in the ring, `Session.command()` /
  `Session.shot()` matches that replayed line and times out waiting for `#2`.
  For this audit, the host script drained the initial replay before issuing
  `ping` and commands in a single session.

## What works

| Area | Observation |
| --- | --- |
| **Sleep / wake & Lock Screen** | `key power` dims/sleeps the display; pressing `key power` again wakes to the Lock Screen (`100% Charged`, `4:13`). `swipe` up from bottom unlocks cleanly |
| **Side keys** | `key volup` and `key voldown` display and animate the left-edge Volume HUD; no press-linked PMIC power-off |
| **Spotlight & keyboard** | Search pill opens Spotlight; on-screen QWERTY taps type accurately (`set`, `can`, `clo`), Top Hit updates and launches Safari |
| **Control Center & Notification Center** | Top-right swipe opens Control Center (blurred backdrop, sliders, toggles); top-left swipe opens Notification Center / Lock Screen overlay |
| **App Library** | Swipe past Home Screen opens App Library (shows Safari, Settings, Photos, App Store, Phone, Messages) |
| **Core apps** | **Settings** (top level, **Display & Brightness**, **Battery**, **General**, **FaceTime**), **Safari** (cold launch takes ~4–7 s; renders Favorites & URL bar), **Messages** ("No Messages"), **Phone** (Keypad & Recents), **App Store** ("LOADING" spinner, expected offline) |

### New evidence on existing issues

- **#6 (Composition):** Lock Screen camera icon is also tinted dark red alongside the pink/red clock (`4:13`/`4:16`); Spotlight status bar has a white diagonal-dotted artifact; `PosterBoard` crash at boot (`sig 5`) likely explains or contributes to the missing wallpaper.
- **#8 (Performance):** Cold app launches take ~4–7 s (Safari is still on a black launch screen at 3 s, rendered by 7 s).
- **#10 (Blur):** App Library search pill and Home Screen `Search` pill render white-on-white; App Library background turns solid white while Control Center blur renders normally.
- **#11 (Backlight/audio):** `key power` sleep dims the framebuffer in software (`~5%` dark image still visible in `shot`) while the physical backlight stays on.
