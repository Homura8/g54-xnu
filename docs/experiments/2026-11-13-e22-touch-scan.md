## Stock driver and firmware (5-8-6 package, host-only analysis)

`super` (LP metadata, 6 GiB raw) → `vendor_dlkm_a` and `vendor_a` (both EROFS):

| Item | Path | Size | EROFS layout |
| --- | --- | --- | --- |
| Driver | `vendor_dlkm:/lib/modules/nova_0flash_mmi_v2.ko` | 301,776 | 3 (LZ4 compressed) |
| Firmware | `vendor:/firmware/novatek_ts_fw.bin` | 139,264 | 3 |
| MP criteria | `vendor:/firmware/novatek_ts_mp.bin` | 139,264 | 3 |

`0flash` and the module string `nvt_bootloader_reset_noflash` mean a
**flashless** TDDI. The host downloads the touch firmware over SPI at
every boot, and LK does not, so a G54 touch driver must do it. The firmware
is Motorola/Novatek material: never commit it. Load it at run time from
the iOS root, or append it to the payload from `out/`.

## Extracted (erofs-utils 1.9.4, installed with the owner's approval)

`dump.erofs --cat` gives `out/touch/novatek_ts_fw.bin` (139,264 B, SHA-256
prefix `ee3f50e76db3909ac645`), `novatek_ts_mp.bin` and
`nova_0flash_mmi_v2.ko` (an AArch64 relocatable, **not stripped**). Its
symbols match Novatek's public nt36xxx SPI driver flow:
`nvt_bootloader_reset_noflash_locked` → `nvt_write_firmware` →
`nvt_boot_ready`/`nvt_check_fw_reset_state` → `nvt_ts_work_func`. Kept in
`out/` only.

## G54 touch hardware (dtbo overlay 0, fragments 47/48; base DTB)

| Item | Value |
| --- | --- |
| Bus | `spi3@11013000`, `compatible = "mediatek,mt6983-spi"`, GIC SPI `0x1ce`; Novatek at chip-select 0, `spi-max-frequency` 9.6 MHz; `mediatek,pad-select = <0 1 2>` in the overlay |
| SPI3 pins | pinmux `<0x4902 0x4a02 0x4b02 0x4c02>`: GPIO 73–76, function 2 (`GPIO_MODE9` at `0x10005000 + 0x390`, nibbles 1–4, with ruby's layout), drive strength 2 |
| Reset | `novatek,reset-gpio` = GPIO 3 |
| Interrupt | `novatek,irq-gpio` = GPIO 22, flags `0x2001` |
| NT36672C | `novatek,swrst-n8-addr = 0x3f0fe`, `novatek,spi-rd-fast-addr = 0x3f310` |
| Clocks | SPI3 `clocks = <topck 0x6c>, <topck 0x0f>, <infra_ao 0x0d>` (`parent-clk`, `sel-clk`, `spi-clk`); MT6855 offsets are not in the DTB (see the clk module in `vendor_dlkm`) |

Ruby's `bsd/dev/ruby_spi3.c` drives the same SPI3 address (FIFO mode, ≤32-byte
transfers), but with MT6877 board values (pins 160–163, its clock-gate bit
and mux). Check its register use against the mt6983-generation IP before
reusing it.

## Touch plan

1. Decompress the EROFS LZ4 files (erofs-utils `fsck.erofs --extract`, or
   a z_erofs compact-index reader) to get `novatek_ts_fw.bin`.
2. Kernel patch `0202-g54-novatek-touch`: MediaTek SPI3 transport (ruby's

   the APSL patch.
3. Keys: `mediatek,kp` at `0x1c00e000` (hardware key 0 = KEY_VOLUMEDOWN);
   power key on the PMIC.
